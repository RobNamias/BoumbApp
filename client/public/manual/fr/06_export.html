💾 Export & Enregistrement

← Retour à l'index

1. Enregistrement Live

Capturez votre performance en direct instantanément.

  • Cliquez sur le Bouton Enregistrement (Rond Rouge) dans la barre de transport.
  • Jouez votre morceau (mutez des pistes, jouez du synthé, etc.).
  • Cliquez sur Stop quand vous avez fini.
  • Entrez un nom et téléchargez le fichier audio .webm.

2. Export Offline (WAV)

Rendez votre arrangement complet proprement.

  • Arrangez votre morceau dans le mode Skyline.
  • Allez dans le Menu Projet > Exporter WAV.
  • Choisissez un nom de fichier.
  • Le moteur va calculer votre morceau plus vite que le temps réel.
  • Téléchargez le fichier .wav haute qualité (16-bit PCM).
